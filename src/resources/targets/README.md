# Legacy starter targets

The ten files in this directory are retained as historical reference material from the early starter pack. They are not loaded by the current Training target registry.

The active bundled Training targets are loaded exclusively from `src/resources/training-targets-source/**/*.{md,txt}` by `src/targets/bundled.ts`.

Do not add new runtime targets here. Add them to `training-targets-source` and keep this directory unchanged unless an explicit archival migration is approved.
