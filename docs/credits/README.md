# Credits and attribution records

This directory preserves supporting records for the authoritative [`CREDITS.md`](../../CREDITS.md) and [`CITATION.cff`](../../CITATION.cff) files in the repository root.

## Contents

- [`CHANGELOG.md`](CHANGELOG.md) records material changes to project credits.
- [`TECHNICAL_REFERENCES.md`](TECHNICAL_REFERENCES.md) explains how external open-source projects and public documentation informed engineering research without implying source-code incorporation or endorsement.
- [`history/`](history/) contains superseded credit records preserved for complete-source archives that do not include `.git` history.

## Maintenance policy

1. Keep the current, authoritative credits in the repository-root `CREDITS.md`.
2. Keep the stable machine-readable citation in the repository-root `CITATION.cff`.
3. Create a historical snapshot only when the accepted credits materially change.
4. Record the reason for each material change in `CHANGELOG.md`.
5. Do not use credits as a substitute for third-party licence notices.
6. Do not describe technical consultation or review as source-code authorship.
7. Record AI project identity separately from model, provider, product, interface, and active development environment.
