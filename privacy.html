Privacy Policy

Last updated: September 27, 2026

AI RV Harness is designed as a local-first desktop application.

Data collected by AI RV Harness

AI RV Harness does not operate its own user accounts, analytics service, advertising system, tracking service, or telemetry backend.

The application does not intentionally send personal information, usage statistics, session content, prompts, research data, or other application data to the project author or maintainer.

Data created within AI RV Harness is generally stored locally on the user's device unless the user chooses to use a feature that communicates with an external service.

Third-party AI providers

AI RV Harness allows users to configure third-party AI providers using their own credentials or API access.

When a user chooses to use such a provider, information required for the requested AI operation may be transmitted directly to that provider. Depending on the feature being used, this may include prompts, conversation content, images, session material, model configuration, or other information intentionally submitted for processing.

AI RV Harness does not control how third-party providers process, retain, log, or use information received through their services.

Users should review the privacy policy, data-retention terms, and account settings of each provider they choose to use.

API credentials

API credentials configured for external providers are used to communicate with the provider selected by the user.

AI RV Harness does not operate a central service that receives users' provider credentials.

Users are responsible for protecting their credentials and for complying with the terms of the services they connect to.

Local data

Application data may be stored locally on the user's computer, including configuration, sessions, research material, training data, targets, and related records.

Users remain responsible for protecting their local computer, backups, exports, and any files they choose to share.

Network communication

AI RV Harness may require network communication when the user chooses to access a remote AI provider or another explicitly configured external service.

The application should not be considered an offline application while such services are being used.

Third-party services

Third-party services are governed by their own terms, privacy policies, security practices, and data-retention rules.

The AI RV Harness project is not responsible for the privacy practices of independent third-party providers.

No sale of personal data

The AI RV Harness project does not sell personal data.

The project does not operate an advertising network or user-profiling service.

Changes to this policy

This Privacy Policy may be updated when the application's data flows, integrations, or privacy-related functionality change.

The current version should be published with the AI RV Harness project documentation and website.
